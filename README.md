📌 JavaScript Form Validation & Character Counter
📖 Overview

This project includes two simple JavaScript-based web applications:

A Registration Form with Real-Time Validation
A Text Area with Real-Time Character Counter

These projects demonstrate basic front-end development skills using HTML, CSS, and JavaScript.

🚀 Project 1 – Registration Form Validation
🔹 Description

A simple registration form that validates user input in real time.

🔹 Features
Validates Name field (cannot be empty)
Validates Email format (must be valid)
Validates Password (minimum 6 characters)
Displays instant error messages
Submit button disabled until all fields are valid
🚀 Project 2 – Real-Time Character Counter
🔹 Description

A text area that tracks and displays character usage as the user types.

🔹 Features
Displays maximum character limit (e.g., 200)
Shows live character count (e.g., 150/200)
Updates in real time while typing
Prevents typing beyond the limit
Displays a warning message when limit is exceeded
🛠️ Technologies Used
HTML
CSS
JavaScript
🎯 Purpose

These projects help beginners understand:

Form validation techniques
DOM manipulation
Event handling in JavaScript
Real-time user interaction
